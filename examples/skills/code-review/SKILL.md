---
name: code-review
description: Review code changes for concrete bugs and regressions.
---
Read the changes and surrounding code before reporting findings. Prioritize
correctness, regressions, and missing error handling. Explain each finding with
a file location, the triggering conditions, and its impact. Separate confirmed
bugs from open questions. If no issues are found, say so and describe what was
reviewed. Follow the user's scope and existing tool approval requirements.
